# Contributing

Thanks for considering a contribution to this project.

## How to contribute

1. Fork the repository.
2. Create a feature branch.
3. Make your changes and test them locally.
4. Open a pull request with a clear summary.

## Guidelines

- Keep changes focused and minimal.
- Do not commit secrets, API keys, or private configuration.
- Ensure the app still builds locally before submitting.

## Validation

Run the following before submitting:

```bash
npm install
npm run build
```
